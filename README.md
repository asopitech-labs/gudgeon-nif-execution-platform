# GUDGEON

**Gudgeon Unified Debuggable Guest Execution Orchestrator for NIF**

GUDGEON is an execution platform for NIF-based programs. It provides interpreted execution, native compilation, first-class debugging, instrumentation, and bidirectional native interoperability under a shared execution model.

Unlike a compiler backend that only emits native code, GUDGEON treats lowered program IR as an executable representation. The same program model can be interpreted, compiled ahead of time, inspected by a debugger, and instrumented by profiling or tracing tools.

**Interpreted. Native. Observable.**
